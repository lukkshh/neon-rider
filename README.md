# Neon Rider 🏎️✨

Neon Rider is a simple, browser-based 3D arcade driving game with neon synthwave vibes. Built using Three.js and Vite, it drops you onto an endless glowing highway where you dodge traffic, hit nitro boosts, and chase high scores.

> **Note:** This is a personal, fully vibe-coded / AI-assisted experimental project. It's meant to be fun, casual, and iterative rather than a polished production game.

---

## Current Status

The project is currently in early prototype stage. It is playable right in your browser with:

* Basic 3D car controls (steering, acceleration, braking, nitro boost)
* Endless highway generation with roadside scenery and retro synthwave horizon
* Traffic cars, road hazards, and collectible energy orbs
* Collision detection and near-miss bonuses
* Procedural synth audio engine (engine rumble, sound effects, and background beats generated live with Web Audio)

Both the code and gameplay are experimental and constantly evolving as new ideas get vibe-coded in.

---

## Future Direction

Because this is an evolving experiment, development happens incrementally. Here are some of the directions and improvements planned over time:

* **Better movement & game feel:** tighter steering, drifting mechanics, tactile camera feedback
* **More interesting environments:** winding roads, elevation shifts, tunnels, and neon cityscape themes
* **Obstacles & challenges:** dynamic traffic behaviors, construction barriers, and road hazards
* **Scoring & progression:** difficulty scaling, combo meters, and distance milestones
* **Visual & audio polish:** enhanced post-processing bloom, screen shakes, and richer synth music
* **Better UI:** sleeker HUD, race summary screens, and mobile touch polish
* **Online features & leaderboards:** global high scores to compete with friends
* **Multiplayer / ghosts:** asynchronous ghost runs and replay features down the road

## Running Locally

If you'd like to try it locally:

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
